    Help for developers new to a codebase

    FlowMind also explains code, diagnoses errors and writes up what a session taught.

    Code explainer

    Turns a convoluted module into mental models, responsibilities and usage recipes.

    flowmind --explain sample_repo/rewards.py

    Error diagnostician

    Reads stack traces, flags anti-patterns such as mutable defaults, and drafts the fix.

    flowmind --debug "AttributeError: ..."

    Architectural guide

    Maps a change against your domain layer boundaries before you write any code.

    flowmind --guide "Add Redis cache"

    Retrospectives

    Writes a “what we learned” brief with ruled-out dead ends and trade-offs.

    flowmind --retro session_004

    Run it in production

    The distributed stack uses a Redis CAS state bus, NATS JetStream, OpenTelemetry tracing through Jaeger, and local Firecracker sandboxes over vsock.

    # Start the full stack
$ docker compose up --build

# Open the client cockpit
$ flowmind serve
